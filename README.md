# DoktorABC landing page

A responsive landing page built with HTML, CSS, and vanilla JavaScript.

## Run locally

From the project root, run:

```sh
npx serve .
```

Then open the local URL printed in the terminal (typically `https://github.com/eleneu18/doktorabc`).

## Responsive carousel controls

Carousel arrows and pagination dots are hidden on desktop when every card is already visible. In that layout the controls have no additional content to reveal. They remain available on mobile, where cards extend beyond the viewport and can be navigated horizontally.
